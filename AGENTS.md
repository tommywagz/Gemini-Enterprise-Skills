# Gemini-Enterprise-Skills

Actual Agentic Solutions temporary development repository for the Gemini Enterprise Agent Skills Garden.

Build agent skills using the standard package architecture: a `SKILL.md` with a name, routing description, and actionable prompt, plus only the `scripts/`, `references/`, and `assets/` folders the skill needs. The [README.md](README.md) is the catalog and status record for skills already made.
